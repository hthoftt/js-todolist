# TODO LIST 待辦清單

以原生 JavaScript 實作的待辦事項應用。

[線上 Demo](https://hthoftt.github.io/js-todolist/)

## 功能
- 新增待辦事項
- 依「全部、待完成、已完成」篩選
- 顯示待完成項目數量
- 一鍵清除已完成項目
